## Что игнорирует .gitignore


В файле `.gitignore` используются следующие обозначения встроенного языка шаблонов системы Git:
- `*` — любая последовательность символов (в том числе пустая);
- `**` — любая вложенность директорий;
- `/` в конце — правило применяется к директории, а не к файлу;
- строка без `/` — правило применяется к файлам и папкам с таким именем на любом уровне.

С учётом этих правил в файле `.gitignore` будут игнорироваться:

- `.terraform/` — папка с таким именем.
- `*.tfstate` — файлы, заканчивающиеся на `.tfstate`.
- `*.tfstate.*` — файлы, содержащие `.tfstate.` в имени.
- `crash.log` — конкретный файл.
- `crash.*.log` — файлы вида `crash.<что угодно>.log`.
- `*.tfvars`, `*.tfvars.json` — файлы с такими расширениями.
- `override.tf`, `override.tf.json` — конкретные файлы.
- `*_override.tf`, `*_override.tf.json` — файлы, оканчивающиеся на `_override.tf` / `_override.tf.json`.
- `.terraformrc`, `terraform.rc` — конкретные файлы.
